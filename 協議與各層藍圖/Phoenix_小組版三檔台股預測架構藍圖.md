# Phoenix 小組版：三檔台股多時間尺度深度學習預測架構

## 專案目標

以小組指定的三檔台股為目標，使用 5 分鐘至日線的 5–6 個時間尺度，融合量價訊號與新聞特徵，建立多時間尺度深度學習金融預測模型。模型須預測多個未來期限的價格路徑、趨勢延續或反轉，以及可能轉折時間窗；不以預測下一根 K 線作為唯一任務。

主要績效以每檔目標股完整測試集的成本後總損益衡量，並檢查模型在其他指定指數／商品上的魯棒性。本階段包括資料、模型、離線部位與損益訓練、視覺回放；不包括全市場搜尋、跨商品資金配置或真實帳戶下單。

## 資料流

```text
多尺度行情 → Layer 1 量價特徵 →（可選 Layer 1.5 參數優化後回 Layer 1）─┐
新聞來源 → Layer 1.7 Silver 新聞事件 → Layer 1.8 Gold 新聞特徵 ────────┤
                                                                     ↓
Layer 1 對齊量價與新聞特徵 → Layer 2（多尺度表徵序列）→ Layer 2.1（多期限預測）→ Layer 2.2（部位政策與全序列損益訓練）
        ↑_________________________________________________________________________│
                              訓練梯度反導

行情／新聞＋凍結模型輸出＋回放帳本 → Layer 2.N 視覺回放
```

## 各層責任與交付

### Layer 1：多尺度量價訊號

- **輸入：**三檔目標股各時間尺度的行情量價資料，以及 Layer 1.8 按標的與可用時間標記的新聞特徵序列。
- **工作：**計算各尺度量價特徵，並由 Layer 1 的特徵對齊流程按決策時間向後對齊新聞特徵；保留標的、時間及尺度資訊，不使用決策時間之後才可用的資料。
- **輸出：**量價與新聞特徵合併後的多尺度特徵包，附簡易說明，供 Layer 2 使用。

### Layer 1.5：特徵參數優化（可選）

- **輸入：**Layer 1 特徵的候選參數及訓練／驗證資料。
- **工作：**比較候選參數對下游多期限預測及成本後損益的影響；只有採用設定後能改善驗證結果時才啟用。
- **輸出：**採用的參數、比較結果及簡易說明；由 Layer 1 依採用參數重新計算特徵。

### Layer 1.7：新聞池

- **輸入：**經核定的新聞來源及三檔目標股；歷史回補與即時採集可分別處理。
- **工作：**保留原始標題與正文、來源、發布時間、實際擷取／可用時間、內容版本及標的關聯；明確標示歷史內容是否有證據證明在當時已可取得。
- **輸出：**欄位一致且可追溯的 Silver 新聞事件，至少帶有事件與來源識別、標的、原始內容、時間資訊、內容雜湊及歷史可用性狀態，供 Layer 1.8 使用。未驗證歷史版本的資料須保留其狀態，不得視為已確認的歷史可用新聞。

### Layer 1.8：新聞 NLP 特徵

- **輸入：**Layer 1.7 的 Silver 新聞事件；訓練或校準時可使用對應期間的市場資料，推論時只使用當時已可用的新聞與交易日曆。
- **工作：**驗證及清理文本、辨識重複事件與新穎度，抽取文字情緒、事件方向／波動影響、事件類型、信心及影響持續時間；文字情緒與對標的的預期市場影響分開表示。依可用時間及交易日曆形成衰減中的新聞狀態，包含隔夜影響標記，不補造行情 K 線。
- **輸出：**可追溯至新聞事件與內容版本的語意結果，以及按標的與可用時間更新的新聞特徵序列，交由 Layer 1 對齊至各尺度決策時間；Layer 1 再將合併特徵交給 Layer 2。Layer 1.8 不輸出交易方向指令、部位、成交或損益。

### Layer 2：多尺度深度表徵

- **輸入：**Layer 1 按決策時間對齊的 5–6 組多尺度量價與新聞特徵。
- **工作：**訓練並比較 TimeMixer++ 多尺度模型、Mamba 多尺度融合模型，以及單尺度深度學習對照模型；依決策時間整合各尺度資訊。
- **輸出：**序列形式，每個決策時間點輸出一個 128 維融合表徵，交由 Layer 2.1 預測不同期限；接口形狀為「批次 × 決策時間點 × 128」。這是第一版 Layer 2→2.1 共用接口，TimeMixer++、Mamba 與單尺度對照模型都需映射到此接口。每個 128 維向量融合截至該時點可用的多尺度量價與新聞資訊；它不是把整段資料壓成單一向量，也不是每個尺度各輸出 128 維。128 維是目前工程規格，尚不代表已證明為最佳寬度。
### Layer 2.1：多期限預測

- **輸入：**Layer 2 每個決策時間點輸出的 128 維表徵序列。
- **工作：**解碼不同未來期限的價格路徑及幅度，預測趨勢延續／反轉、轉折機率與可能時間窗，並表示預測不確定性。
- **輸出：**多期限預測序列，供 Layer 2.2 形成部位政策及計算全序列訓練目標。
### Layer 2.2：部位政策與全序列損益回饋

- **輸入：**Layer 2.1 的預測；訓練時使用後續實際結果與交易成本形成訓練目標，不作為 Layer 2 的推論輸入。
- **工作：**依預測形成逐時點部位，計算整段序列的成本後損益與風險，並將訓練結果回饋 Layer 2 與 2.1，使模型參數能依整段表現更新。具體訓練方法由負責組員設計。
- **輸出：**部位路徑、預測／動作／模擬成交與成本／後續實際走勢帳本，以及整段損益與回撤結果，供訓練評估和 Layer 2.N 回放。
### Layer 2.N：可視化回放介面

- **輸入：**標的、相容的已訓練模型、行情與新聞資料，以及 Layer 2.2 回放帳本。
- **工作：**使用者拖入標的後載入模型，以時間軸逐步回放預測及部位變化。
- **輸出：**圖表呈現預測路徑、趨勢與轉折、進出點、後續實際走勢、成交成本、損益及回撤，讓使用者定位錯誤進場並檢視模型表現。介面標記不直接更新模型參數。

## 訓練與驗收

Layer 2.2 的梯度更新只使用訓練資料；驗證資料用於選擇模型與設定；完整封存測試集只評估凍結模型。逐檔報告三檔目標股的成本後總損益、最大回撤、交易成本及單位時間損益；其他指定指數／商品分別報告魯棒性，不以合併數值掩蓋個別結果。
